## Shared fields inherited by every catalogue entry

Every row below inherits these fields unless its row explicitly overrides them. Purpose: isolate a capability before adding task complexity. Hypothesis: the stage's primary score improvement and engineering acceptance will meet a **stage-specific threshold that must be registered before execution**. Controls: initial random-weight policy, reproducible random actions, and a frozen legal quantized scripted benchmark. Training: scratch initialization, independent RNG/model/optimizer/pool, historical self-play. Policy: actor2x128/tanh, four-frame local history; critic2x256/tanh, team combined observations; PPO/GAE/Adam with the Stage A settings [TORCHRL]. Observations: personal/public geometry and visible entities only; actions: categorical movement/yaw/pitch/fire/reload, interaction only for bomb games. No respawns during an elimination round. Immutable opponent snapshots use50%latest/50%history, initial+8history, snapshot10updates [engineering choice informed by SF20].

Seeds, compute and hyperparameters for **deferred** rows are provisional: no runnable configuration exists and **allowance is zero until a separate protocol/budget is authorized and pushed**. Proposed first confirmation seeds follow5101/5102/5103 only for Stage A; future seeds require disjoint registered namespaces. Main stages start from scratch; transfer never silently substitutes for them. Controls and final-test seeds are frozen before use. Metrics: initial/final paired round score, wins/draws/losses, side/team breakdown, elimination/timeouts, damage/accuracy/kills, inactivity, reward components and optimizer diagnostics. Success: preceding stage's acceptance plus new stage-specific generalization criteria, resolved before execution. Stop: deadline, nonfinite state, violated interface/data isolation or failed prerequisite; retain failed/incomplete results. Failure interpretation: distinguish implementation fault, exploration/reward failure, map difficulty and insufficient evidence. Artifacts: config/source/checkpoint hashes, raw logs/metrics/evaluation, per-experiment Markdown, aggregate/PDF updates, model card and replay. Dependency: immediately preceding accepted capability unless a row names another.
