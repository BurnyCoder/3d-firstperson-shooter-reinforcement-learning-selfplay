# Probe e16_t4

Original execution reference: one self-play learner, seed 8002, 16 arenas, four PyTorch CPU threads, CUDA updates. Four measured updates after one warmup supplied 8,192 arena steps. Aggregate throughput was **736.85 steps/s** over 11.117577 seconds; the raw worker rate was 736.849057 steps/s. Group process wall time was 28.265 seconds, including startup, warmup, and an extra collection profile excluded from throughput.

Collection used 82.87% and optimization 16.69% of the measured worker interval. This motivated overlapping independent learners' CPU collection and GPU updates. Peak live PyTorch CUDA allocation was 156,522,496 bytes; total device memory and utilization were not measured here. The probe succeeded. One short measurement supplies no confidence interval or playing-quality evidence.
