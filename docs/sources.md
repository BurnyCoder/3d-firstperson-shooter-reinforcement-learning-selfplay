# Shared bibliography and attribution

Verified primary sources accessed 2026-10-23. References support the specific methods below, **not** our chosen coefficients, success thresholds or a 12-hour convergence promise. Approved user requirements are the source of the staged progression and numerical engineering defaults. Software versions are pinned in `uv.lock`; version families below describe the interfaces used. This list is shared by code, protocols, reports and model cards.

| Key | Primary source | Supported use and boundary |
|---|---|---|
| TORCHRL |[TorchRL0.14 multi-agent PPO tutorial](https://docs.pytorch.org/rl/stable/tutorials/multiagent_ppo.html), [EnvBase](https://docs.pytorch.org/rl/stable/reference/generated/torchrl.envs.EnvBase.html), [ClipPPOLoss](https://docs.pytorch.org/rl/stable/reference/generated/torchrl.objectives.ClipPPOLoss.html) |Library collection, TensorDict multi-agent axes, PPO and GAE. | SF20 |[Petrenko et al., ICML2020](https://proceedings.mlr.press/v119/petrenko20a/petrenko20a.pdf), [supplement](https://proceedings.mlr.press/v119/petrenko20a/petrenko20a-supp.pdf), [official VizDoom integration](https://www.samplefactory.dev/09-environment-integrations/vizdoom/) |Doom self-play, factorized controls, population diversity, efficient collection; their APPO/V-trace/PBT setup is not MiniStrike PPO.
