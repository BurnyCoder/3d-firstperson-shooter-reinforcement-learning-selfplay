# Shared bibliography and attribution

Verified primary sources accessed 2026-10-23. References support the specific methods below, **not** our chosen coefficients, success thresholds or a 12-hour convergence promise. Approved user requirements are the source of the staged progression and numerical engineering defaults. Software versions are pinned in `uv.lock`; version families below describe the interfaces used. This list is shared by code, protocols, reports and model cards.

| Key | Primary source | Supported use and boundary |
|---|---|---|
| TORCHRL |[TorchRL0.14 multi-agent PPO tutorial](https://docs.pytorch.org/rl/stable/tutorials/multiagent_ppo.html), [EnvBase](https://docs.pytorch.org/rl/stable/reference/generated/torchrl.envs.EnvBase.html), [ClipPPOLoss](https://docs.pytorch.org/rl/stable/reference/generated/torchrl.objectives.ClipPPOLoss.html) |Library collection, TensorDict multi-agent axes, PPO and GAE. We call library implementations; our environment/masking/self-play orchestration is original. Stable URLs may move; lockfile and run metadata identify actual versions. |
| SF20 |[Petrenko et al., ICML2020](https://proceedings.mlr.press/v119/petrenko20a/petrenko20a.pdf), [supplement](https://proceedings.mlr.press/v119/petrenko20a/petrenko20a-supp.pdf), [official VizDoom integration](https://www.samplefactory.dev/09-environment-integrations/vizdoom/) |Doom self-play, factorized controls, population diversity, efficient collection; their APPO/V-trace/PBT setup is not MiniStrike PPO. Large published frame counts do not forecast our learning time. No code copied from Doom assets or trained models. |
| FTW19 |[Jaderberg et al., Quake capture-the-flag paper](https://arxiv.org/abs/1807.01281) |Population learning, recurrent memory, learned reward weights; human/built-in-bot evaluation is distinct from their learned self-play training. Not Counter-Strike and not a reproduction target here. |
| UNITY |[Unity DodgeBall engineering account](https://unity.com/blog/engine-platform/ml-agents-plays-dodgeball), [official environment](https://github.com/Unity-Technologies/ml-agents-dodgeball-env) |Later variable-team observations and team credit assignment inspiration. Blog intended reward behavior is not a guarantee that every repository revision implements it identically; do not copy coefficients/code without checking. |
| MA-POCA |[Cohen et al., On the Use and Misuse of Absorbing States in Multi-agent RL](https://arxiv.org/abs/2111.05992) |Posthumous team credit and attention-based team representations; not our claimed training algorithm. |
| NG99 |[Ng, Harada, Russell, ICML1999](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf) |Potential difference `gamma*Phi(next)-Phi(current)` and discounted telescoping; terminal potential zero. No assertion of self-play convergence follows. |
| COLAS18 |[Colas et al., How Many Random Seeds?](https://arxiv.org/abs/1806.08295) |Independent-run variability and power sensitivity, not a promise that three seeds suffice. |
| AGARWAL21 |[Agarwal et al., Deep RL at the Edge of the Statistical Precipice](https://arxiv.org/abs/2108.13264) |Uncertainty-aware evaluation; our match pairing and three-model estimand are explicitly described in the active protocol. |
| PYTORCH |[distributions](https://docs.pytorch.org/docs/stable/distributions.html), [serialization](https://docs.pytorch.org/docs/stable/notes/serialization.html) |Factorized categorical probabilities, safe tensor-based checkpoints, immutable state copies. |
| PYTHON |[Python3.12 dataclasses](https://docs.python.org/3.12/library/dataclasses.html), [subprocess](https://docs.python.org/3.12/library/subprocess.html), [datetime](https://docs.python.org/3.12/library/datetime.html) |Configuration contracts, process orchestration and UTC deadline accounting. |
| SCIPY |[noncentral t distribution](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nct.html) |Conditional power calculations under the stated normal paired-difference assumptions. |
| MATPLOTLIB |[3.11.2 line plotting](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.plot.html), [error bars](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.errorbar.html), [figure export](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html), [annotated heatmaps](https://matplotlib.org/stable/gallery/images_contours_and_fields/image_annotated_heatmap.html), [stacked horizontal bars](https://matplotlib.org/stable/gallery/lines_bars_and_markers/horizontal_barchart_distribution.html) |Original reporting glue calls these APIs for PNG/SVG curves, paired match intervals and evaluation breakdowns. No example function is copied. Axis/layout choices are engineering decisions; numerical sources are the adjacent evidence receipts. |
| NUMPY-PLOTS |[First differences](https://numpy.org/doc/stable/reference/generated/numpy.diff.html), [guarded division](https://numpy.org/doc/stable/reference/generated/numpy.divide.html); actual runtime version in `uv.lock` |Original accounting code converts cumulative telemetry into interval rates, preserves undefined denominators and rejects decreasing unsigned counts. Definitions come from our logger, not a claim about optimal RL metrics. |
| URSINA |[official FPS example](https://github.com/pokepetter/ursina/blob/master/samples/fps.py) |Presentation inspiration retained from original implementation; our renderer does not use the example's collision/controller physics. See existing architecture documentation. |

No new third-party source files are vendored in Stage A. Existing dependency licenses remain in their packages; do not imply that an external game's art/assets are licensed for this project.
