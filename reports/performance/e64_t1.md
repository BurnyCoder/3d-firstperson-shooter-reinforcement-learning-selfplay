# Probe e64_t1

One self-play learner, seed 8002, 64 arenas, one PyTorch CPU thread, CUDA updates. Four measured updates after one warmup supplied 32,768 arena steps. Aggregate throughput was **1,078.60 steps/s** over 30.380170 seconds; the raw worker rate was 1,078.601100 steps/s. Group process wall time including startup and warmup was 50.203 seconds.

Collection used 72.96% and optimization 26.86% of the measured worker interval. Peak live PyTorch CUDA allocation rose to 390,735,872 bytes. More arenas improved throughput, but also changed each learning batch from 2,048 to 8,192 arena-time rows. This option was not applied to the primary experiment because a fixed arena-step budget would then contain fewer optimizer update cycles. The probe succeeded; its performance cannot be interpreted as evidence of better learning.
